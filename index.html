How to run the applications

Follow these steps after downloading any of the applications.

1

Download the application

Click the download button for the application you want to use and download the ZIP file.

2

Extract the ZIP file

Right-click the downloaded ZIP file and select Extract All. Open the folder created after extraction.

3

Run the application

Open the extracted folder and find the application's .exe file. Double-click the EXE file to start it.

4

Keep the application window running

Once the application starts, a window will appear showing that the application is running. You can minimize this window, but do not close it.

Important: Do not close the application window while using the app. Closing the window will stop the application from working. You can safely minimize the window and continue using the application.

Information

These are Windows applications designed to run locally on your computer. Download the ZIP file, extract it, and run the included .exe file. Some applications open a local service in the background, so the application window must remain running while you use the software.
